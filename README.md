# 中国象棋

原木棋盘、水墨背景的中国象棋，支持同屏双人和在线私人房间。原生浏览器前端与 Node.js 房间服务共用规则引擎，无第三方运行时依赖。

## 本地运行

需要 Node.js 22 或更高版本。

```sh
npm run dev
```

打开 `http://127.0.0.1:4193/xiangqi/`。在线测试使用两个独立标签页或浏览器：一方创建房间，另一方输入房间号加入，由房主开始。同屏对局保存在当前浏览器，在线身份保存在当前标签页的会话存储。

## 规则与交互

完整约定见 [rule.md](rule.md)。保留基本走法，允许不解将、送将和将帅照面；实际吃掉对方帅／将才获胜并弹窗。将死、困毙、长将及重复局面不自动结束游戏。主动结束或退出不判胜负。

选择棋子后显示合法落点；点击落点预览，再点击该落点或确认按钮走棋。合法移动有距离相关的平移动画，非法走棋原地抖两次并短暂显示原因。系统开启减少动态效果时，以静态边框和文字反馈替代动画。

在线动作由服务端验证，包含版本检查和幂等标识；实时同步中断时禁止提交走棋并自动重连。悔棋、求和、再来一局须另一方同意。在线悔棋每方每局两次。

## 素材与设计

`assets/images/pieces/` 的 14 张透明 WebP 来自真实木质棋子素材，在 Pixso 中制作可复用组件后导出并压缩；32 枚棋子各自渲染，支持独立走棋与吃子。图片总量从 2,053,923 字节压缩至 381,906 字节（减少 81.4%）。棋盘和棋子提前加载并解码后再展示，版本化图片使用浏览器长缓存；HTML 和脚本要求重新校验，避免缓存旧规则。棋盘与背景使用独立图片，棋位按原木棋盘的九路十行交点定位。设计色彩见 `design/tokens.json`。

## 验证和构建

```sh
npm test
npm run check
npm run build
```

测试包含规则、在线身份、并发版本、幂等重试、协商、存档、房间过期和 SSE；集成测试需要允许本地回环监听。构建仅复制运行文件白名单到 `dist/`，输出内容哈希版本和逐文件 SHA-256 清单 `release.json`，排除设计源、测试、私人配置和房间数据。

## 部署接口

运行 `dist/server/app.js`，用 `HOST`、`PORT` 指定回环监听地址；`DATA_FILE` 应指向发布目录之外的持久存档文件。服务使用原子重命名保存房间。经本机可信反向代理转发时可设置 `TRUST_PROXY=1` 并由代理覆盖 `X-Real-IP`。

代理应保留 `/xiangqi/` 路径，对 SSE 关闭缓冲并允许长连接。`/xiangqi/api/health` 返回运行版本；部署后比对 `release.json` 与构建清单，并验证双端对局。生产路径、服务配置和回滚记录保存在忽略目录 `.local/`。
